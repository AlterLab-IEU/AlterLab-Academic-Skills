# Disclosure & Citation Templates for Generative-AI Use

Source-backed citation templates (APA and MLA as revised in 2025) plus a
student AI-use declaration block. A Restricted or Permitted tier (see `tier_framework.md`) is only complete
when it tells students **exactly** how to disclose and cite — never "cite it
appropriately."

## Contents

1. APA 7 (Style)
2. MLA 9 (Style)
3. Chicago (note option)

## 1. APA Style

APA's September 2025 guidance replaced its 2023 "How to cite ChatGPT" example
(`OpenAI. (2023). ChatGPT (Mar 14 version) …`). The **author is the AI company**,
not the tool and not the student, and there are now two reference forms:

**A specific chat** — use when the chat generated ideas, content, or information
the student used. Share the chat and cite its link:

```
AI Company. (Year, Month Day). Title of chat [Generative AI chat]. Tool name/model. URL of shared chat
```

**The tool in general** — use for functional help such as editing or organizing
the student's own writing:

```
AI Company. (Year). Tool Name/Model [Large language model]. URL of tool
OpenAI. (2025). ChatGPT (GPT-5) [Large language model]. https://chatgpt.com/
```

- **Title:** italic in both forms (the chat title, or the tool/model name).
- **In-text:** parenthetical `(OpenAI, 2025)`; narrative `OpenAI (2025)`.
- Adapt company, date, title, model, and link to what the student actually used;
  do not invent a model string or URL.

> Source: APA Style blog, *Citing generative AI in APA Style: Part 1 — Reference
> formats* (McAdoo, Denneny & Lee, 9 September 2025), apastyle.apa.org; the
> templates above match the UBC and Oregon State University library summaries of
> that post (checked 2026-09-23).

## 2. MLA Style

MLA uses its template of core elements and treats the AI tool as the **container,
not the author** (MLA explicitly does not recommend listing the tool as author).
Works Cited template (MLA Style Center, revised August 2025):

```
"<Description of prompt>" prompt. ChatGPT, model <model name>, OpenAI, <date generated>, <shareable chat URL>.
```

MLA's own example from the revised post:
`"Describe the theme of nature in Jane Austen's Mansfield Park" prompt. ChatGPT,
model GPT-4o, OpenAI, 23 Sept. 2024, chatgpt.com/share/66f1b0a0-d704-8000-be9a-85f53c850607.`

Core elements MLA names:

1. **Title of source** — describe what the AI generated (include the prompt).
2. **Title of container** — the AI tool, italicized (e.g. *ChatGPT*).
3. **Version** — the specific model or model version (the 2025 revision's change).
4. **Publisher** — the company that made the tool.
5. **Date** — when the content was generated.
6. **Location** — the stable, shareable URL of the conversation; the tool's
   general URL only if it has no share feature (the other 2025 change).

MLA also requires writers to **acknowledge functional uses** of AI (editing
prose, translating) in a note or in the text, even when nothing is quoted.

> Source: MLA Style Center, *How do I cite generative AI in MLA style? (Updated
> and Revised)*, August 2025, style.mla.org/citing-generative-ai-updated-revised/.

## 3. Chicago (note option)

For courses using Chicago notes, disclose AI use in a note. Chicago's published
guidance treats AI-generated text like personal communication and recommends a
**note** rather than a bibliography entry, e.g.:

```
1. Text generated by <Tool>, <Company>, <date>, <URL>.
```

> Confirm the current wording against the Chicago Manual of Style Online (18th
> edition and its Q&A) before publishing — this option is
> offered as a starting note form, not a fixed template. If you cannot confirm
> it, fall back to APA or MLA above.

## 4. The student AI-use declaration block

Append this to each Restricted/Permitted submission. It is the practical artifact
that makes disclosure enforceable. Fill-ins in `<…>`:

```
AI-Use Declaration
- Did you use any generative-AI tool on this submission?  [ ] No   [ ] Yes
- If yes, which tool(s) and model/version(s), and when:  <tool, model, date used>
- For which parts / sub-tasks:  <e.g. brainstorming the outline only>
- How you verified anything the tool produced:  <e.g. checked every cited source against the library catalog>
- Citation(s) included per the course documentation standard:  [ ] Yes  [ ] N/A
I confirm the assessed work is my own and that any AI use complied with the
tier stated for this assignment in the syllabus.
Signature: ____________________   Date: ________
```

## 5. What disclosure must always state

Whatever the format, a complete disclosure names:

- **Which tool and version** was used,
- **For what** (which sub-tasks),
- **How the student verified** the output (AI can fabricate facts and citations),
- and includes the **citation** in the course's documentation standard.

A policy that says "disclose AI use" without specifying these four is flagged by
`scripts/policy_lint.py` as an incomplete disclosure clause.
