# Experimental dataset description (fictional lab, for an eval)

**Fictional example.** This describes a made-up experiment; no data file accompanies it.

Coral heat-stress tank experiment, 2025.

- 48 aquarium tanks, each holding six fragments of *Acropora* sp. from three source reefs
  (two fragments per reef per tank)
- Treatments, fully crossed: temperature 27, 29, 31 or 33 °C x light 150 or 400
  µmol photons m^-2 s^-1 x feeding (none / daily zooplankton); 3 tanks per combination
- Duration: 28 days after a 7-day ramp
- Measured per fragment every 4 days: Fv/Fm (PAM fluorometry), colour score (CoralWatch card,
  1-6), symbiont density (cells cm^-2, days 0 and 28 only), survival
- Measured per tank daily: temperature, pH, dissolved oxygen
- Known issue: two tanks at 33 °C had a heater failure for 18 h on day 12
- Hypotheses already considered (please avoid): "higher temperature lowers Fv/Fm" and
  "feeding improves survival"
