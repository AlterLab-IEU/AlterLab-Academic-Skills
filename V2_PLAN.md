# AlterLab-Academic-Skills v2.0 — "Trust & Reach Release"

# Vision
v2.0 turns the loudest credibility objection — "academic skills are just prompts with no evals" — into AlterLab's headline differentiator by backfilling executable evals across all 180 skills, shipping a deterministic citation-existence + claim-faithfulness gate, and making every helper script and cross-skill reference provably correct in CI. On top of that trust substrate it makes the corpus actually installable and discoverable everywhere: spec-conformant per-domain bundles that clear claude.ai's caps, a generated `skills.json` catalog that kills doc drift, honest K-Dense fork provenance in the license file, and the latent plugin surface (35 core agents, slash commands, bundled academic MCP) activated. The faculty-life/research-lifecycle domain and humanities white space are explicitly deferred to a v2.x ROADMAP so v2.0 stays a focused, shippable trust-and-reach release rather than a net-new-authoring sprawl.

## Breaking changes & migration notes
- **Eval schema migration** from `{query, expected_behavior, should_trigger}` → canonical `{skill, evals:[{id, prompt, expected_output, assertions}]}`. The 6 existing core `evals.json` change format. Mitigated by a one-shot `scripts/migrate_eval_schema.py`; `should_trigger` survives as an assertion type so no behavioral regression.
- **`pyproject.toml` 1.1.0 → 2.0.0 (major bump)** while marketplace/package were at 1.2.0. Versions are now derived from pyproject; any external tooling reading the old hardcoded `gen_marketplace.VERSION` constant breaks.
- **TOP-LINE INSTALLED-USER MIGRATION (highest-impact change):** correcting marketplace `source:"./"` scoping (#1087) means installing one plugin no longer silently loads all 180 skills. CHANGELOG must carry an explicit BREAKING entry: *"If you previously installed `alterlab-core` and relied on it loading every skill, you must now install each domain plugin you use (e.g. `alterlab-bioinformatics`)."* This is gated as a blocking precondition (see ws-1) — if single-repo 13-plugin scoping does not work, the bundle/marketplace plan changes shape before any agent runs.
- **`shared/handoff_schemas.md` becomes `shared/*.schema.json` + is vendored into bundles** — the canonical on-disk location and format referenced by core skills change; the 3 citing SKILL.md files (research-pipeline, deep-research, paper-writer) update in lockstep.
- **CI gates flip from advisory to gated** (compileall/ruff, eval-shape, 500-line body cap once `known_failures` drains, description cap 1024) — PRs that regress will fail rather than warn. The 1024 cap is zero-risk (max real description is 886 chars; nothing fails on adoption).
- **mermaid `references/diagrams/*.md` moves up one level** — reference paths cited in that SKILL.md and any external links change; flattened and re-cited atomically.
